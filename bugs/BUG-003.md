# BUG-003: Prisma CLI не запускается на Windows с командой `npx prisma`

Окружение: Windows 11, Node.js 24.21.0, npm 11.19.0, Prisma 7.10.0

Шаги воспроизведения:
1. Установить проект через `npm install`.
2. Выполнить `npx prisma generate`.

Ожидаемый результат: Prisma Client успешно генерируется в `server/generated/prisma/`.

Фактический результат: Команда `npx` не находится в PATH. Вместо выполнения команды Windows открывает файл `prisma.js` в браузере. Команда `where npx` не возвращает ничего.

Severity: Major
Priority: High

Причина: На некоторых установках Node.js в Windows утилита `npx` не попадает в PATH. Windows вместо неё находит файл `prisma.js` в текущей папке и ассоциирует его с браузером.

Обходной путь: Использовать прямой путь к Prisma CLI:
`node_modules\.bin\prisma.cmd generate`
`node_modules\.bin\prisma.cmd migrate dev`
`node_modules\.bin\prisma.cmd db seed`

Рекомендация: Задокументировать этот обход в README (что и сделано в разделе «Запуск проекта»).

Статус: Исправлен (через документацию обходного пути)
