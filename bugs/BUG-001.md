# BUG-001: Кнопка удаления карточки не срабатывает

Окружение: Chrome 130, Windows 11, staging

Шаги воспроизведения:
1. Открыть доску.
2. Навести курсор на карточку — появится крестик удаления.
3. Кликнуть на крестик.

Ожидаемый результат: Карточка удаляется, список обновляется.

Фактический результат: Клик обрабатывается, но карточка не удаляется. В консоли ошибка: `deleteCard is called with undefined`.

Severity: Major
Priority: High

Причина: Функция `deleteCard(cardId)` ожидает аргумент `id`, но в `DraggableCard.jsx` пропс `onDelete` передавался без аргумента:
`<Card onDelete={onDelete} />` вместо `<Card onDelete={() => onDelete(id)} />`. В итоге `cardId` всегда был `undefined`.

Исправление: Обернуть вызов в стрелочную функцию и передавать `id` явно.

Статус: Исправлен
