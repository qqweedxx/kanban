# BUG-002: WIP-лимит не срабатывает при добавлении карточки через кнопку «+»

Окружение: Chrome 130, Windows 11, staging

Шаги воспроизведения:
1. Войти как admin.
2. Открыть колонку «In Progress» (WIP-лимит = 3).
3. Добавить 3 карточки.
4. Нажать «+ Добавить карточку» в этой же колонке.
5. Ввести текст и подтвердить.

Ожидаемый результат: Всплывает предупреждение о достижении WIP-лимита, карточка не добавляется.

Фактический результат: Карточка добавляется, лимит игнорируется. Предупреждение не появляется.

Severity: Major
Priority: High

Причина: Проверка WIP-лимита была реализована только в `handleDragEnd` (для drag-and-drop), но отсутствовала в функции `addCard`, которая вызывается при нажатии кнопки «+».

Исправление: Добавлена проверка `targetColumn.wipLimit !== null && targetColumn.cards.length >= targetColumn.wipLimit` перед вставкой новой карточки.

Статус: Исправлен
