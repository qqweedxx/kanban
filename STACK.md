# Обоснование выбора стека

**Проект:** Kanban-доска
**Команда:** Беликова, Галанова

## Выбранный стек

- **Frontend:** React + TypeScript (Vite)
- **Backend:** Node.js + Express 5
- **БД:** SQLite + Prisma ORM
- **Аутентификация:** JWT + bcrypt
- **Тестирование:** Jest, Supertest, Playwright, k6, OWASP ZAP
- **CI/CD:** GitHub Actions

## Обоснование

1. **React** — компонентный подход, огромная экосистема, легко найти готовые библиотеки (dnd-kit для drag-and-drop).
2. **Express** — минималистичный и гибкий фреймворк, легко писать тесты, много примеров.
3. **SQLite** — не требует установки отдельного сервера БД, идеально для лабораторной. Файл `dev.db` рядом с проектом.
4. **Prisma** — типобезопасный ORM с миграциями из коробки, автогенерация клиента.
5. **JWT** — стандарт для SPA, stateless, легко тестируется.
6. **Jest + Supertest** — стандартные инструменты для тестирования Node.js API.
7. **Playwright** — кросс-браузерный E2E, работает с Chrome, Firefox, Edge.
8. **k6** — простой синтаксис на JS, легко писать нагрузочные сценарии.
9. **GitHub Actions** — встроен в GitHub, бесплатный для публичных репозиториев.

## Альтернативы

- **Vue / Angular** — отклонены: команда не имеет достаточного опыта.
- **PostgreSQL** — избыточен для лабораторной, требует установки и запуска сервера.
- **MongoDB** — не подходит для реляционных связей (проект → доска → колонка → карточка).
- **Cypress** — отклонён: Playwright быстрее и поддерживает больше браузеров.
